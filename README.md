# 🛒 Amazon Clone - HTML & CSS

A frontend **Amazon homepage clone** built using HTML and CSS to practice web development and UI design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

## ✨ Features

- Amazon-style navigation bar
- Search bar
- Promotional banner
- Product category sections
- Icons using Font Awesome
- Clean and structured layout

## 🎯 Purpose

This project was created as part of my journey to learn and improve my **frontend web development skills**.
